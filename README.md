# Makoto_EDC
Emotion Detection Chatbot by Yassmine Omari.

## Summary
This research focuses on developing an emotion detection chatbot as an emotional support system for students. The problem statement highlights the challenges of expressing emotions due to social media trends and the negative impact it can have on a students mental health.

Advanced technologies such as machine learning and sentiment analysis have been utilised to train the chatbot model. Techniques such as supervised machine learning are employed using generated datasets of texts and corresponding emotions including anger, sadness, joy, fear, disgust, shame, and guilt. The data is categorised based on tags, patterns, and responses. Tags representing the intent (anger, sadness, ...), patterns representing possible user inputs, and responses representing possible chatbot output.

Various libraries and packages were used including NLTK, JSON, NumPy, Sklearn, tensorflow, WordNetLemmatizer, Sequential SGD, Confusion matrix, and stopwords. Different model architectures and parameters were tested as well, but overfitting remained to be a challenge, leading to inaccurate results during testing.


## Conclusion
This research concludes that building and developing an emotion detection chatbot as an emotional support system for students is a complex task, involving challenges related to overfitting, model stability, as well as data availability and contextual understanding. Although efforts were made to train the model using supervised learning techniques, the model still exhibited overfitting issues.

Despite these challenges, the research highlights the importance of providing students with a method of expressing their emotions and seeking support anonymously. It emphasises the need for further improvements in model architecture, parameter turning, data collection, and data preprocessing techniques to enhance the accuracy of the chatbot. This research also shows how emotions can not be limited since the human emotions are hard to contextualise
